# Wanderlust 🏡

Wanderlust is an Airbnb-inspired web application where users can explore places to stay, create property listings, and share their experiences through reviews.

✨ Features

🔐 Secure User Authentication & Authorization

🏠 Create, Edit & Delete Property Listings

🔍 Explore and Browse Accommodations

🖼️ Property Image Uploads

⭐ Reviews and Rating System

📍 Property Location Information

📱 Responsive User Interface

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript, EJS, Bootstrap
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** Passport.js



## Project Structure

- `models/` – Database schemas
- `routes/` – Application routes
- `controllers/` – Request handling logic
- `views/` – EJS templates
- `public/` – CSS, JavaScript and images
- `middleware/` – Authentication and other middleware

## Security

- Environment variables for sensitive credentials
- Authentication and authorization for protected routes
- Server-side input validation
